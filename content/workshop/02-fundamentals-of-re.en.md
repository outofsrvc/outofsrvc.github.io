## 5. Low-Level Programming

The most important matter in reverse engineering is learning and understanding Assembly code. Why?
Because when reverse engineering any program, we are dealing with executable code in machine language (Machine Code), that is, it is represented in zeros and ones (Binary System).

But this code can be disassembled (Disassemble) so that it appears in a readable language, namely Assembly. We have therefore prepared a complete series dedicated to the x86 Assembly language.
